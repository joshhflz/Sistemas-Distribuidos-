## Especificaciones del sistema:
- Tendra 5 nodos, uno por cada integrante.
- Serán 5 laptops que se comuniquen entre si por medio de una red privada.
- Cada laptop tendra un front end y un backend
- Si una falla, se podra resincronizar con la base de datos del resto de las laptops.
